# 우리집 자금계획 디자인 감사

감사일: 2026-08-23  
대상: https://family-finance-plan.eomkun12.chatgpt.site/

## 총평

전체적인 시각 완성도는 좋습니다. 절제된 색, 둥근 카드, 큰 숫자 중심의 계층 구조가 일관되고, 특히 투자 관리 화면은 데스크톱과 모바일 모두 안정적입니다. 다만 모바일 자금 계획의 고정지출 영역은 실제 가로 넘침이 발생하고, 동일 대출의 월 납입액이 화면 내에서 다르게 표시되어 우선 수정이 필요합니다.

## 화면별 상태

1. 자금 계획 데스크톱 — 대체로 양호. 핵심 요약은 잘 읽히지만 페이지가 길고 대출 정보가 반복됩니다.
2. 투자 관리 데스크톱 — 양호. 계좌, 수익률, 자산배분의 위계가 명확합니다.
3. 자금 계획 모바일 — 수정 필요. 390px 화면에서 문서 폭이 482px까지 늘어나 고정지출 3열 일부가 잘립니다.
4. 투자 관리 모바일 — 양호. 카드가 자연스럽게 한 열로 재배치됩니다.
5. 보유자산 상세 펼침 — 양호. 상호작용과 포커스 표시가 확인됩니다.

## 우선순위별 발견사항

- **P1 — 모바일 고정지출 레이아웃:** 390px 뷰포트에서 3열 구조가 유지되어 가로 스크롤이 생기며, 한국어 항목명이 글자 단위로 줄바꿈됩니다. 모바일에서는 1열 또는 2열로 전환하고 카드 최소 폭을 해제해야 합니다.
- **P1 — 대출 월 납입액 불일치:** `퇴직금 담보대출`이 로드맵에서는 월 448,111원, 고정지출에서는 412,000원으로 표시됩니다. 단일 데이터 원본으로 통합하고, 수동 조정 값이라면 명확한 설명이 필요합니다.
- **P2 — 긴 자금 계획 흐름:** 요약, 대출 로드맵, 계산기, 입력, 기록이 한 페이지에서 반복되어 탐색 비용이 큽니다. 상단에 요약과 다음 행동을 남기고 상세 입력·기록은 접거나 앵커 이동을 제공하는 편이 좋습니다.
- **P2 — 작은 글자와 조작 영역:** 차트 범례와 보조문구가 9–10px이고, 일부 탭 높이는 32px, 삭제 버튼 폭은 약 13px입니다. 모바일 보조문구는 최소 11–12px, 주요 터치 영역은 44px 내외가 안전합니다.
- **P2 — 초기 렌더링 안정성:** 운영 화면에서 React hydration mismatch 오류가 확인됐습니다. 현재는 표시되지만 첫 로딩 깜빡임이나 상태 교체 위험이 있어 원인을 확인해야 합니다.
- **P2 — 입력 가능 여부:** 일부 숫자 입력란이 읽기 전용 통계 카드처럼 보여 편집 가능한지 즉시 알기 어렵습니다. 라벨, 테두리, 포커스 색, 편집 아이콘 중 한두 가지를 일관되게 사용하세요.
- **P3 — 세부 완성도:** 한글 영문 세리프 이탤릭 혼용, 투자 카드의 불균형한 빈 공간, 상단 탭과 중복되는 뒤로가기 버튼, 모바일에서 사라지는 브랜드명이 조금 덜 정제돼 보입니다.

## 강점

- 톤이 절제되어 가족 자산 서비스에 필요한 안정감과 신뢰감을 줍니다.

- 도넛 차트가 장식에 그치지 않고 범례와 함께 실제 비교를 돕습니다.
- 빈 상태 안내와 보유자산 상세 펼침 흐름이 자연스럽습니다.
